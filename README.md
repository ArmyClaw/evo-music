# 🧬 Evo Music — 自进化音乐引擎

> 从乐理基础到自主创作，AI的音乐进化之路。

## 阶段规划

### Phase 1: 乐理基础
- [ ] 音阶系统（大调/小调/五声）
- [ ] 和弦进行生成
- [ ] 节奏模式库
- [ ] MIDI 输出

### Phase 2: 旋律生成
- [ ] 马尔可夫链旋律
- [ ] 情感映射（调式 ↔ 情绪）
- [ ] 旋律连贯性优化
- [ ] 简单旋律评测

### Phase 3: 编曲引擎
- [ ] 多声部编排
- [ ] 动态变化（渐强/渐弱）
- [ ] 结构生成（A-B-A曲式）
- [ ] 鼓点模式

### Phase 4: 进化机制
- [ ] 适应度函数（人类偏好学习）
- [ ] 遗传算法优化旋律
- [ ] 风格迁移
- [ ] 自我评价与迭代

### Phase 5: 完整创作
- [ ] 全曲生成（3-5分钟）
- [ ] 混音与效果
- [ ] Web Audio 实时播放
- [ ] 与网站风格联动

## 技术选型
- **生成**: Python + MIDIUtil
- **播放**: Web Audio API
- **进化**: 遗传算法 + 自定义适应度
